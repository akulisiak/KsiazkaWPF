## Opis projektu
CalcPy to podstawowy kalkulator napisany w języku Python. Funkcje jakie posiada to: dodawanie, odejmowanie, mnożenie i dzielenie. Program posiada zabezpieczenia typu wyłapanie błędu przy dzieleniu przez 0. 
## Wymagania
- Python 3.6 lub nowszy
- System operacyjny: Windows / Linux / macOS (działa wszędzie)
## Instalacja
1. Sklonuj repozytorium: git clone https://github.com/twojlogin/calcpy.git
2. Przejdź do folderu wpisując w terminalu: 
```bash
cd calcpy
```
3. Uruchom program wpisując w terminalu: 
```bash
python calc.py
```
## Szybki start
Przykładowa interakcja z programem:
```bash
python calc.py
Wybierz działanie (+, -, *, /): +
Podaj pierwszą liczbę: 5
Podaj drugą liczbę: 3
Wynik: 8
```
